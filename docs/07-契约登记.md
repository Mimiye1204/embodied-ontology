## 2. 版本号语义

- 语义化版本 `x.y.z`：破坏性变更升大版本，加字段/加端点升小版本，修 bug 升补丁。
- **版本号进载荷**：C1 载荷带 `view_schema_version`；C2 文档顶层带 `exchange_version` 与 `ontology_version`。
- C3/C4 用 `schema_migrations`（SQL）/ `:SchemaMigration`（Neo4j）登记版本。
