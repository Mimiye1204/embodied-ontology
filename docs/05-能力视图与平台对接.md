# 05 · 本体能力视图与调度中台对接

> 本体引擎 → 调度中台（robot-dispatch）的**输出契约**。
> 能力视图 = 本体的一个投影：每台机器人「现在能干什么、受什么约束、有没有故障」，
> 平台据此做任务分配与能力展示。JSON-LD 导出能力同时完善（过滤切片）。

## 1. 定位

- 本体图是**全量知识**（语义层 + 实例）；调度中台只需要**决策所需的投影**。
- 能力视图把「机器人 → 能力 → 部件 → 健康」这条链路拍平成一个文档，
  平台无需理解 Neo4j/图结构，直接反序列化消费。
- 视图是**派生只读**的：从本体投影，不反向写回；双向同步经 JSON-LD 全图交换（docs/03）。

## 2. 能力视图 Schema

`schema/capability_view.yaml`（LinkML，独立 `cv:` 命名空间，自包含）：

```
CapabilityView（根文档）
├── id                 cv:view/capability
├── generated_at       生成时间
├── ontology_version   来源本体 Schema 版本
├── robots: [RobotCapability]
│     ├── id / serial / model / status
│     ├── capabilities: [CapabilityEntry]
│     │     ├── code / label
│     │     ├── part_ids        提供该能力的部件
│     │     ├── healthy         全部提供部件健康
│     │     └── degraded        存在降级（无故障）
│     ├── constraints: [ConstraintEntry]   适用约束（code/type/expression/threshold/unit）
│     └── active_faults: [FaultEntry]      活跃故障（event_id/mode_code/severity/status/detected_at）
└── metrics: [MetricEntry]                 测点注册表（metric_code/measures_entity/binds_to/unit/value_type/aggregation）
```

## 3. 生成与消费

**生成**（`eo/views.py`）：
```python
view = build_capability_view(store, robot_id=None)   # 纯 JSON（平台契约）
view = view_as_jsonld(view)                           # JSON-LD（语义自描述）
```

**给 Go 后端的结构体**（LinkML → JSON Schema / Go）：
```bash
.venv/Scripts/gen-json-schema schema/capability_view.yaml > generated/capability_view.schema.json
# 或直接生成 Go 结构体：gen-golang schema/capability_view.yaml
```

**平台对接流程**：
1. 平台 `GET` 能力视图（本体引擎暴露的接口 / 或订阅 JSON-LD 快照）
2. 按 JSON Schema 反序列化成 Go struct（quicktype / gen-golang 产物）
3. 任务分配时按 `capabilities[].code` + `healthy` + `constraints[]` 过滤可用机器人
4. 测点接入按 `metrics[]` 注册表校验合法 (entity, metric) 键（时序外键约束来源）

## 4. JSON-LD 导出完善（过滤切片）

`export_jsonld(store, path, types=None, ids=None)`：

| 参数 | 语义 |
|---|---|
| `types` | 只导出指定 ObjectType（如只导 Robot） |
| `ids` | 只导出指定实体 id + 其直接引用（一跳）的节点 |

CLI：
```bash
.venv/Scripts/python.exe cli.py export --types Robot,Capability --out generated/robots.jsonld
.venv/Scripts/python.exe cli.py export --ids eo:task/grasp-egg          # 含引用闭包
.venv/Scripts/python.exe cli.py view --robot eo:robot/ti5              # 能力视图（纯 JSON）
.venv/Scripts/python.exe cli.py view --jsonld                          # 能力视图（JSON-LD）
```

活跃故障条目 / JSON-LD 类型注入 / 按类型导出 / 按 id 引用闭包导出。
